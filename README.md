# Teams e IA na Prática — TNC

Material do workshop da DC Cruz. Os exemplos usam dados fictícios.

Site: https://educrvz.github.io/tnc-workshop/

## Atualizar o site

Edite `index.html`, `sessao-1.html`, `sessao-2.html`, `sessao-3.html`, `style.css` ou `app.js` e faça commit diretamente em `main`. O GitHub Pages publica automaticamente as alterações; não é necessário abrir pull request nem obter aprovação.

Fernanda pode editar pelo botão de lápis no GitHub após aceitar o convite de colaboração. Selecione a opção de commit direto em `main`. A atualização pode levar alguns minutos.

Este repositório contém somente o site. Não inclua notas internas, documentos originais, dados reais de participantes ou gabaritos.
